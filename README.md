# RelayDesk for Mac

Public distribution for the RelayDesk Mac companion. This repository contains release documentation and, when available, signed and notarized Mac installation packages. Application source code is not published here.

- [Download page](https://relaydesk-7qf.pages.dev/)
- [Setup and help](https://relaydesk-7qf.pages.dev/help/)
- [Privacy information](https://relaydesk-7qf.pages.dev/privacy/)
- [Mac releases](https://github.com/chenyang-charles/relaydesk-releases/releases)

## Availability

The public Mac release is in preparation. No installer is available yet. The iPad app is also not publicly available.

The planned first Mac distribution supports Apple silicon and macOS 14 or later. Future public releases will be signed with Developer ID, notarized by Apple, and accompanied by SHA-256 checksums. Release versions support Sparkle update checks; installation requires user confirmation and waits until remote sessions and pairing have ended.

## Distribution only

GitHub hosts the installation archives. Cloudflare Pages serves the download page, help, privacy information and, after the first release, the signed update feed. This repository is separate from the application development workspace.
